# Huzaifa's Calculator - A Flutter App

## Overview
Huzaifa's Calculator is a simple yet powerful calculator app built using Flutter. It supports basic arithmetic operations, user-friendly UI, and real-time calculations. The app leverages the `math_expressions` package to evaluate expressions efficiently.

## Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division.
- Expression evaluation using `math_expressions` package.
- Clear (AC) and Delete (DEL) functionality.
- "Ans" button to recall the last result.
- User-friendly UI with a responsive layout.

## Installation
To run this project on your local machine:
1. Clone the repository:
   ```sh
   git clone https://github.com/HuzaifaLatif13/Flutter-App-Development.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Flutter-App-Development/Calculator
   ```
3. Install dependencies:
   ```sh
   flutter pub get
   ```
4. Run the app:
   ```sh
   flutter run
   ```

## Dependencies
This project uses the following dependencies:
- `flutter`: Latest stable version
- `math_expressions`: For evaluating mathematical expressions
